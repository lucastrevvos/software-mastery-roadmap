# Edge AI · Robotics Software · Physical AI

Trilha de especialização do **Software Mastery Roadmap** para transição lateral de engenharia de software/sistemas distribuídos para **Edge AI, Robotics Software e Physical AI**.

## Objetivo profissional

Entrar progressivamente em funções como:

- Edge Software Engineer
- IoT / Edge Engineer
- Robotics Platform Engineer
- Robotics Software Engineer
- Edge AI Engineer
- Autonomous Systems Software Engineer

## Como a trilha funciona

- prioridade para documentação, cursos e learning paths oficiais;
- certificações apenas quando agregarem sinal profissional real;
- hardware caro não é necessário no começo;
- cada fase termina em um **Mastery Gate**;
- candidaturas começam antes da conclusão total da trilha;
- Isaac Sim é especialização avançada, não pré-requisito.
