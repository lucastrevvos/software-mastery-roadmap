00.1 · Terminal & Filesystem

ComandoUso
pwdDiretório atual.
ls / ls -laLista conteúdo; -la inclui detalhes e ocultos.
cd <dir> / cd ..Navegação.
mkdir <dir>Cria diretório.
touch arquivoCria arquivo vazio/atualiza timestamp.
cat arquivoMostra conteúdo em stdout.
echo "texto" > arquivoSobrescreve arquivo.
echo "texto" >> arquivoAcrescenta ao final.
cp origem destinoCopia.
mv origem destinoMove/renomeia.
rm arquivoRemove arquivo.
rmdir dirRemove diretório vazio.
which comandoQual executável o PATH encontra.
echo $PATHDiretórios de busca de executáveis.

ComandoUso
ps / ps auxInspeciona processos.
sleep 100 &Processo em background para experimentos.
jobsJobs do shell.
kill <PID>Envia sinal ao processo.
echo $$PID do shell atual.
ps -o pid,ppid,cmdPID, pai e comando.
echo $?Exit code do último comando.
comando 2> error.txtRedireciona stderr.
comando1 | comando2Pipe: stdout → stdin.
envVariáveis de ambiente.
export APP_ENV=developmentExporta variável aos filhos.
chmod +x run.shPermissão de execução.
./run.sh / bash run.shExecuta script.

00.3 · Bytes, texto e encoding

ComandoUso
printf 'A' | xxdInspeciona bytes hexadecimais.
printf 'Olá 🙂' | wc -cConta bytes.
printf 'Olá 🙂' | wc -mConta caracteres.
file arquivoTenta identificar tipo/encoding.
xxd arquivoHex dump.
hexdump -C arquivoOffset + bytes + texto.
diff a bDiferença textual.
cmp a bComparação byte a byte.
sha256sum a bHash dos bytes.
printf 'linha1\nlinha2\n' > lf.txtCria LF.
printf 'linha1\r\nlinha2\r\n' > crlf.txtCria CRLF.
printf '\xEF\xBB\xBFhello\n' > bom.txtCria UTF-8 com BOM.

00.4 · Git

ComandoPergunta que responde
git initQuero iniciar um repositório.
git statusEm que estado está working tree/staging?
git add <arquivo>Que versão irá para o próximo snapshot?
git commit -m "mensagem"Quero registrar este estado.
git diffWorking Tree × Staging.
git diff --stagedStaging × último commit.
git log --onelineQual é o histórico compacto?
git log --oneline --decorateOnde estão HEAD e branches?
git show <HASH>O que este commit fez?
git branch <nome>Criar ponteiro de branch.
git switch <branch>Trocar branch.
git switch -c <branch>Criar e trocar.
git merge <branch>Integrar histórico.
git clone <URL>Criar clone local.
git pullBuscar/integrar atualizações remotas.

Git · investigação de regressão

ComandoUso
git log --oneline -- app.pyHistórico só daquele arquivo.
git show <HASH> -- app.pyAlteração do commit naquele arquivo.
git diff <HASH>^ <HASH> -- app.pyCommit suspeito × pai imediato.

Fluxo: reproduzir → medir → histórico → commit suspeito → diff → hipótese → correção → medir de novo.

00.6 · Logs

ComandoUso
python3 app.py > app.log 2>&1Captura stdout + stderr.
grep checkout app.logFiltra termo/evento.
grep ERROR app.logProcura erros.
tail app.logÚltimas linhas.
tail -n 20 app.logÚltimas 20.
tail -f app.logAcompanha em tempo real.
grep ERROR app.log | wc -lConta eventos de erro.

00.7 · Profiling

ComandoUso
time python3 app.pyBaseline simples: real/user/sys.
time bash run.shMede fluxo completo.
python3 -m cProfile app.pyPerfil de funções.
python3 -m cProfile -s cumulative app.pyHotspots por tempo acumulado.
python3 -m cProfile -s calls app.pyOrdena por número de chamadas.
/usr/bin/time -v python3 app.pyTempo + métricas extras + memória residente máxima.
topCPU/memória de processos em tempo real.
htopAlternativa amigável, se instalada.
