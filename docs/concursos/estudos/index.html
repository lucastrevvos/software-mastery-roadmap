Revisão expressa — Português

Conectivos

Embora = concessão; porque = causa; portanto = conclusão; porém = oposição; caso = condição.

Voz passiva com “se”

“Registraram-se falhas”: verbo concorda com o sujeito paciente. “Precisa-se de analistas”: singular.

Intercalação

“A equipe, após revisar os logs, respondeu.” Duas vírgulas isolam a expressão intercalada.
