## Portfólio recomendado

### Kotlin Core Lab
Biblioteca pequena com testes JUnit, tratamento de erros, coroutines e Flow, commits, README e explicação de decisões.

### Android Engineering Lab
App de referência evolutivo: v1 telas Compose, rede e Room; v2 offline-first/Hilt/WorkManager; v3 automação, segurança, testes e profiling. Precisa executar a partir de instruções documentadas.

### KM One — Engineering Case Study
Usar apenas informações publicáveis. Explicar arquitetura Android, permissões, limitações de segundo plano, mecanismos de resiliência e decisões técnicas. Nunca expor credenciais, dados de terceiros, logs sensíveis, código restrito ou métricas não medidas.

### Flutter Production Lab
App Dart/Flutter com gerenciamento de estado, API, cache, testes, integração nativa, pipeline e documentação sobre limitações multiplataforma. Builds iOS exigem ambiente Apple apropriado.

Problema; escopo; stack e arquitetura; execução local; testes; decisões/ADRs; segurança/privacidade; desempenho medido quando houver; screenshots ou vídeo sem dados pessoais; trade-offs; limitações; próximos passos; licenciamento.

## Estratégia de conteúdo

Compartilhar engenharia verificável: investigação de crash/ANR, escolha de lifecycle, concorrência em coroutines, erro de sincronização offline, melhoria real de startup, pipeline GitHub Actions ou trade-offs Android x Flutter. Preferir demonstrações, perfis de execução e métricas reais a slogans e métricas inventadas.

## Portas de candidatura

- **Mobile Android:** Kotlin, Compose, lifecycle, Room, APIs, testes e app demonstrável.
- **Android Senior:** experiência relevante em decisões, arquitetura, confiabilidade, performance, segurança e code reviews, com evidências.
- **Flutter:** Dart, estado, plugins, testes, performance e build/distribuição.
- **Mobile + Backend:** .NET, contratos REST, autenticação, sync/offline e integração ponta a ponta.

Candidatar-se assim que atender aos requisitos relevantes de uma vaga, sem necessariamente concluir todas as fases. Inglês técnico, revisões de código e explicação de decisões serão treinados junto com os projetos.
