Arquitetura evolutiva

Codex: monólito modular → Git / Linux / Docker → AWS / CI/CD → Operação e incidentes → Redis / RabbitMQ → Extração de serviços → CQRS / MongoDB → Kubernetes / SRE

Codex extrai primeiro um serviço de referência; estudante extrai outro com o tutor. Tecnologias entram com problema, ADR e evidência. O domínio proposto cobre identidade, clientes, catálogo, estoque, pedidos, pagamentos simulados, notificações, expedição e auditoria.

Produção didática

Tráfego sintético configurável, infraestrutura operacional real e incidentes sem causa revelada. Sem staging permanente; testes automatizados e CI efêmero. Isolamento de clientes reais, limites de custo, taxa e escopo, rollback, stop switch e aprovação antes de provisionar serviços pagos.

DECA: Descomplicar → Experimentar → Corrigir → Avançar. Runtime Lens em todos os exemplos de código e simulações de infraestrutura; distinguir simulação e observação real. Sem marcar domínio por implementação do Codex.
