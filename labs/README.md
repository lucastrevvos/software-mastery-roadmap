# Labs

Aqui ficam os exercícios ativos do Programming Mastery Lab.

Cada laboratório deve ter um ID único, requisitos, critérios de entrega e foco explícito nas competências avaliadas. A solução do aluno fica dentro da própria pasta do lab.

Fluxo: `pull → resolver → testar → commit → push → revisão → correção → mastery/review/error-ledger`.
