# Projects

Projetos integradores unem competências de múltiplas fases do roadmap e servem como evidência de portfólio.

Eles não substituem os laboratórios curtos: labs isolam habilidades; projects testam integração, decisões de engenharia, trade-offs e execução de ponta a ponta.
